# GREENIX

**Official Windows downloads, installation instructions, and release updates.**

GREENIX is a Windows desktop companion for PS5 players. It is designed to work alongside **Chiaki-NG** and supports a DualSense-to-virtual-controller workflow.

> **Important:** This repository contains public downloads and documentation only. The GREENIX source code is maintained separately.

## Downloads

Official installer packages will be published on the [Releases page](https://github.com/BRKENZI/GREENIX-Downloads/releases).

- Download only files published in an official GREENIX release.
- Check the release notes and version number before installing.
- Do not download unofficial copies from third-party websites.

## Installation

See **[INSTALLATION.md](INSTALLATION.md)** for the Windows setup guide, controller configuration, and troubleshooting.

## Requirements

- A supported Windows PC.
- A PS5 console and network connection.
- **Chiaki-NG**, installed separately.
- The controller/virtual-device components required by your GREENIX release. Follow the release-specific instructions; do not install drivers from unofficial sources.

## Controller setup note

For the HidHide configuration used by GREENIX:

1. Add the installed `GREENIX.exe` to HidHide's **Applications** list.
2. Hide the physical Sony DualSense device only.
3. Do **not** hide the Virtual DS4 device.
4. Enable device hiding.
5. Start GREENIX, then start Chiaki-NG.

Device names and menus may vary by driver version. If your controller stops working, close GREENIX and Chiaki-NG before reviewing the HidHide configuration.
